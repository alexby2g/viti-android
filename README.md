# VITI Flutter

Cliente nativo multiplataforma de **VITI · producto de AGR Studio**.

Este repositorio parte vacío y se usa como base única para:

- Android (APK / AAB)
- Windows (aplicación de escritorio)
- iOS en una fase posterior

La aplicación **no replica la lógica de negocio**. Laravel + Neon siguen siendo la fuente única de verdad para autenticación, permisos, empresas, solicitudes, proyectos, pagos, archivos, mensajería y estados.

> El nombre histórico del repositorio es `viti-android`; el producto dentro del código es VITI Flutter y soportará también Windows.
